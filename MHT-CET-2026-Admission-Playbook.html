4   Round-by-Round Playbook (every step until she is seated)

Stage 0 — Before CAP opens (do this NOW)

  • ☐ Renew NCL (Non-Creamy Layer) — must be valid for FY 2025–26 (it is annual!). Most common reason students lose their quota.
  • ☐ Renew Income Certificate (< ₹8L, current FY) — needed for both TFWS and MahaDBT.
  • ☐ Keep ready: OBC Caste Certificate, Caste Validity (or application receipt), Domicile/Nationality, SSC + HSC marksheets, CET scorecard, photo, sign, Aadhaar.
  • ☐ Confirm name spelling is identical across every document.

Stage 1 — Registration & E-Scrutiny

  • ☐ Fill application; select Candidature Type A (Maharashtra).
  • ☐ Upload clear scans (no glare, full page).
  • ☐ Tick TFWS = Yes and select OBC + Ladies reservations correctly.
  • ☐ Wait for status "Confirmed". If any document is rejected, re-upload immediately.
  • Exit check: provisional merit list shows OBC category + TFWS eligible + Ladies.

Stage 2 — Choice Filling (make-or-break)

  • ☐ Fill 40–80 choices (more = safer).
  • ☐ For each college-branch, order codes: TFWS ('T') → LOBC → OPEN.
  • ☐ Overall sequence: Dream block → Target block → Safety block.
  • ☐ End the list with 2–3 dead-safe safety codes — never leave it short.
  • Never list a college she would refuse — the system can allot any code typed.

Stage 3 — CAP Round 1

Got a DREAM seat (Cummins/PCCOE/COEP/VJTI)?  -> FREEZE        (done)
Got a TARGET / SAFETY seat?                  -> NOT-FREEZE    (accept + keep climbing)
Got nothing?                                 -> stay in, widen choices for Round 2
  • ☐ Pay the seat-acceptance fee — Not-Freeze only protects her if she confirms.
  • ☐ Report / upload as instructed to lock the seat as her floor.

Stage 4 — CAP Round 2

  • The engine can only upgrade her (never push her down) → NOT-FREEZE is risk-free.
  • ☐ Re-order: push any now-unwanted options below her current seat.
  • ☐ If upgraded to a better seat, confirm again.
  • ☐ FREEZE if she is now happy to finish with the current seat.

Stage 5 — CAP Round 3 / Spot / Institute-level

  • ☐ Gamble here only if she is not yet seated, or the upgrade is clearly worth it.
  • ☐ Do not drop a secured in-budget seat for a risky vacancy.
  • Final: report to allotted college → pay fee → start the MahaDBT 50% reimbursement claim.
